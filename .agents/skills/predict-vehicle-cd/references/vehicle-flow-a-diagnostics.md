# A 方案：当前车辆预测问题与下一轮实验

2026-11-05。用户选择保留 A：完整五视图共享特征与预测 Cd/Cl 一起条件化场解码器。原 A 的三个 31 轮权重保持不变，B 留作对照。本次新增诊断工具和独立续训产物，不修改已保留的预测模型。

## 评估范围与证据

- 系数训练仍为 1,099 条，含全部 26 辆 Cd-only 内置车；场分支训练覆盖 32 个 DrivAer 几何。
- 在相同 34 个 DrivAer 开发验证几何上检查种子 42、43、44。三个种子反复使用同一组几何，不构成 102 个独立案例。没有使用历史测试集或新增 CFD 场标签。
- 每例用原有 65,536 表面点积分；4,096 表面点检查静止壁面；每个外盒面用 24×24 中点采样；原流体采样池、尾流区、车体包围盒外分别取 512 点检查方程残差。
- 同一案例的诊断 RNG 固定为 `20261105 + validation case index`。续训前后使用相同几何、表面样本与诊断点。
- `outputs/predict-vehicle-cd/a-diagnostics-20261105/summary.json` 汇总结果、权重哈希和口径；`verified/A-{42,43,44}.json` 保存逐例结果。原 A 权重哈希与先前 A/B 评估一致，压力与黏性分量相加复现原力积分，最大绝对差小于 1e-6。

## 1 系数可用性：Cd 优于 Cl，积分仍落后于直接预测

以下为三个种子的 MAE 平均值，不是三模型集成预测误差：

| 相同 34 验证几何 | Cd MAE | Cl MAE | 有符号 Cl/Cd MAE |
| --- | ---: | ---: | ---: |
| A 的直接系数头 | 0.007049 | 0.037204 | 0.133977 |
| A 的流场积分 | 0.009744 | 0.041041 | 0.149161 |
| 原始联合系数 CNN，固定单模型参考 | 0.007191 | 0.034421 | 0.123519 |

场积分 Cd 平均相对绝对误差为 3.06%–3.86%。Cl 接近零时逐例百分比不稳定，保留绝对误差和符号诊断。34 例中，三个种子的 Cl 符号错误分别为 5、12、4；仅看 `|真实 Cl| >= 0.02` 的 30 例，仍分别有 4、9、3 例符号错误。因此问题不只来自接近零的标签。

系数头与场积分两条输出也存在差异：各种子逐例平均绝对差为 Cd 0.0070–0.0094、Cl 0.0161–0.0276。当前 API 应持续分别标注两种结果；场输出尚不能替代较成熟的直接系数预测。正、负 Cl 都存在向零收缩的平均偏差，但个别车型和种子会反号，不能用统一偏置修正所有情况。

## 2 已证实的物理约束缺口

下表报告每案例 RMS 的平均值及其三个种子范围，速度以来流 U 归一化：

| 诊断 | 三个 A 种子的范围 | 解释 |
| --- | ---: | --- |
| 车身壁面速度 RMS / U | 0.111–0.133 | 声明的静止无滑移壁面目标为零 |
| 车身壁面法向速度 RMS / U | 0.037–0.045 | 存在预测速度穿透壁面 |
| 壁面 `|法向速度| > 0.05U` 的采样比例 | 12.6%–16.7% | 面积均匀采样下的比例，无局部 CFD 标签 |
| 入口、出口、两侧面的速度误差 RMS / U | 0.302–0.353 | 相对当前实现的均匀来流目标 |
| 外盒净流量 / 外盒总流入量，取绝对值 | 6.3%–7.3% | 只积外盒，车身泄漏另报；不能当成完整域守恒误差 |
| 尾流区无量纲散度 RMS | 0.214–0.255 | 明显高于零，仍有离散采样限制 |

这些指标检验代码自己声明的代理问题，无需真实 CFD 场即可发现不满足约束。它们不等于相对真实 CFD 的速度/压力误差。压力与黏性阻力分解中没有发现负黏性总阻力，但缺少参考分量，无法据此确认剪切预测正确。

当前物理目标也有已知近似：全域固定 `ν_eff = 1/Re + 0.001`、全地面静止无滑移、外盒各面统一指定来流速度和 Cp=0。原记录的 DrivAer 设置包括上游滑移/下游无滑移地面及不同湍流闭合。即使训练满足当前目标，也需要独立确认它与源系数标签相容。

## 4 Re 响应与工况接口仍未验证

固定验证几何 004、022，在三个种子下只改变归一化 log(Re)，使用已记录输入范围的低、中、高点：Re 约 1.111e7–1.295e7。场积分的高低点变化仅为 `|ΔCd| = 1.7e-5–6.6e-5`、`|ΔCl| = 1.3e-5–1.0e-4`。

这是六组内部数值探测，缺少对应 CFD 标签，不能判断真实速度效应应该多大。代码中常数涡黏性 0.001 比该区间的 1/Re 大约四个数量级；由 Re 引起的有效黏性相对变化只有约 0.00128%。条件编码仍有 Re 通路，但现有数据不能解耦速度与几何/来源关联。详见 `reynolds-response.json`。

接口还存在语义缺口：`predict_vehicle` 单独接收 Re，同时要求 conditions 与固定源工况字典一致；尚未检查 `Re = U L / ν` 与实际几何长度及记录的速度/黏度一致。当前探测显式标为反事实条件，不将固定源速度记录当作这些 Re 点的已核实工况。后续应由输入入口统一派生或校验这些量，避免输出互相矛盾的条件记录。

## 5 原因假设与下一步顺序

下列机制有代码依据，但尚未通过单变量实验确定各自的误差贡献：

1. **边界和区域采样不足。** 每次更新只有 128 个壁面点、128 个外边界点和 128 个 PDE 点；PDE 池由 4,096 个全域候选加 65,536 个近壁候选过滤而成，尾流/远场所占比例较少。当前损失把各速度分量和区域压成均值，训练总损失容易掩盖具体位置的问题。下一轮保持 A 网络和 32 个几何，明确按壁面、外边界、尾流、主体流体分配样本，独立报告残差；先核对代理边界定义。
2. **场更新预算与几何数量耦合。** 每轮遍历 1,099 系数样本，batch=64，因此只有 18 次场更新；31 轮总共 558 次，每个场几何约 17–18 次。场几何按列表前 32 个选择，尚未按几何覆盖选样。扩大到更多几何前，需要单独确定每几何更新预算，避免数据增加后训练反而变稀。
3. **局部几何表达有限。** 当前 168 维全局特征与两系数压到 24 维后，通过坐标 MLP 输出场；前部 CNN 冻结，也没有计划中的多尺度三维空间特征。它是否能精确表达不同车身、底盘和尾流位置仍待测。后续可保留 A 的全局系数先验，增加由完整几何学习的空间特征；不额外要求用户提供距壁距离或法向作为网络输入。
4. **工况与泛化证据不足。** 场分支只有单个 DrivAer 车型族；26 辆车只参与系数监督。对同几何、多 Re/偏航/地面/轮速的配对结果仍缺证据，飞机尚不在支持范围。先补边界和输入一致性，再扩大真实几何覆盖，最后单独验证工况变化。

下一轮候选的开发验收应同时看系数、Cl 符号、壁面泄漏、分区边界/散度、独立表面求积与固定权重推理时间。提前固定比较预算和点集；任何系数改善都不能抵消未报告的物理退化。现有 34 例已反复用于开发，后续泛化结论需要另外冻结的新几何评估集。秒级推理路径保持不变，以上优化均在离线训练和验证侧进行。

最终验证：技能测试共 192 项通过；新增诊断与测试文件 Ruff 检查、格式检查通过。测试含现有依赖弃用/未来行为告警，完整输出保存为本次输出目录的 `tests.log`。
