# Cd / Cl 绝对误差读出优化

2026-11-16。按用户最新要求，本轮只优化原始系数单位的Cd MAE和Cl MAE；升阻比、相对误差、改型差值及排序均未参与训练和选择。

已实现绝对MAE续训、内部特征归一化、Cd/Cl梯度平衡及其四组受控训练。**最简单的绝对MAE续训组在总体指标上改善，但部分来源退步；另存探索性候选，默认模型保持原样。** 验证集选出的组合组没有在历史test上保持Cl改善，因此没有将其提升为默认模型。

## 数据和保持项

使用现有2257条车辆记录，1819 train /211 val /227历史test；来源及切分不变，未增加样本或CFD标签。26辆内置参考车仍为Cd-only，Cl伪标签没有进入损失或指标。飞机权重没有修改。

保留五个完整数值深度/掩码视图及共享Cd/Cl头，不增加类别输入或部件图。外部数值合同仍为18项几何/无量纲数值＋18项状态位，Re直接输入；U/L/黏度没有重新加入。

从上一轮只做绝对系数训练的A1第3轮检查点继续。CNN在投影之前固定，训练投影、工况编码、视图融合和共享系数头；冻结特征缓存仅用于加速，最终权重仍可直接读取完整视图。

## 本轮具体改动

| 组 | 内部特征处理 | Cd/Cl绝对MAE训练 |
|---|---|---|
| absolute | 保持原特征尺度 | 两项等权 |
| features | 使用训练侧池化特征均值/标准差 | 两项等权 |
| balanced | 保持原特征尺度 | 按实际梯度范数平衡两项目标 |
| features-balanced | 使用训练侧均值/标准差 | 梯度平衡 |

特征统计只用train；四个普通视图共享统计以保留共享投影，底视图单独统计。标准差下限0.05用于约束内部数值放大，不代表CFD误差阈值。

归一化时同时做等价线性重参数化，起点预测保持一致；全2257案例初始最大差异约Cd 7.14e−8、Cl 4.76e−7。后续差异来自训练，不依赖人为平移输出或修改标签。

损失先将网络输出还原到原始系数单位，再分别计算观测标签的绝对误差。梯度平衡组的两项权重之和固定为2，单项范围0.25～1.75；缺失Cl继续掩码。它是训练内部目标权重，没有计算升阻比或相对精度。

四组均为seed42、40轮、Adam学习率1e−4、batch64；同一初始函数、同一冻结视觉网络和完全相同的抽样序列。每组1160步、72760次训练案例曝光。无图像扰动，所有原始模型/数据另存保护。

## 选择规则和结果

每轮只按验证集来源等权的Cd MAE＋Cl MAE选择，要求两个验证MAE都不高于初始模型。四组全部训练完成后才统一评估历史test。

| 组 | 验证Cd MAE | 验证Cl MAE | 历史test Cd MAE | 历史test Cl MAE |
|---|---:|---:|---:|---:|
| 初始A1 | 0.010045 | 0.042621 | 0.008609 | 0.040658 |
| absolute，第10轮 | 0.009838 | 0.042177 | **0.008325** | **0.040120** |
| features，第40轮 | 0.009856 | 0.041378 | 0.008142 | 0.041172 |
| balanced，第38轮 | 0.009648 | 0.041749 | 0.008429 | 0.041865 |
| features-balanced，第39轮 | **0.009551** | 0.041466 | 0.008528 | 0.041749 |

预先声明的验证选择器选出features-balanced。该组历史test的Cl MAE高于初始模型，本轮不采用它作为默认模型；没有事后改写验证获胜者或选择规则。

预设的最简单控制组absolute在验证和历史test的总体Cd/Cl MAE均下降，保留为可运行的探索性候选。历史test已多次用于开发，本次也参与方案取舍，不能把这个保留决定描述为新的独立盲测收益。

### absolute组逐来源结果

| 来源 | Cd MAE：初始→候选 | Cl MAE：初始→候选 |
|---|---:|---:|
| AhmedML，50条 | 0.009249 → 0.009104 | 0.043447 → 0.042278 |
| DrivAerML，50条 | 0.006510 → 0.006644 | 0.027363 → 0.028366 |

收益主要来自Ahmed/Windsor，DrivAer的Cd/Cl和Rim的Cd退步。总体MAE降低没有证明各类车辆都改善，也没有证明跨基础车族泛化提升。这是保留旧默认、仅提供候选的重要原因。

## 可运行权重和接口

探索性候选：`outputs/vehicle-absolute-readout-20261116/candidate/model.pt`。

absolute组的内部归一化缓冲为恒等映射，导出器只移除已证明恒等的缓冲，不改变任何训练后的神经张量。因此候选继续使用原`vehicle_dimensionless_v1`合同和既有预测入口：

```bash
export PYTHONPATH="$PWD/.agents/skills/predict-vehicle-cd/scripts:$PWD/.agents/skills/predict-aircraft-coefficients/scripts"
python -m vehicle_cd_learning.dimensionless predict \
  outputs/vehicle-absolute-readout-20261116/candidate/model.pt \
  /path/to/re-only-case.json --output /path/to/prediction.json
```

实验中的非恒等归一化权重必须通过`vehicle_cd_learning.readout`加载，旧入口会拒绝其合同，避免静默漏用归一化。它们的训练结果保留供复查，本轮没有启用为默认。

已执行一个DrivAer原网格CLI回放，与对应缓存推理的Cd/Cl完全一致；缓存推理与训练特征评估的差异均低于1e−7。另执行内置Model3缓存预测，仍仅返回Cd。Rim原始数据的直接256光栅化与通用512重采样策略差异沿用原记录，不声称任意来源的原网格回放都已验证。
