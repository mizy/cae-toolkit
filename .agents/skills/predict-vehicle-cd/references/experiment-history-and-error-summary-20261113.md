# 气动系数预测：实验历史、误差来源与改进方向

记录日期：2026-11-13。本文汇总截至该日已完成的实验；各实验的数据、切分和指标口径不同，不能直接混排。默认预测入口和旧权重均未自动替换。

## 当前路线与数据边界

保留方案 A：车辆前、后、右、上、下五个完整视图的数值深度/掩码，结合几何比例与工况，经 CNN 和 attention 共享预测 Cd/Cl。注意力权重不能解释成气动力贡献。最新车辆诊断采用每视图 32 维、约 90173 参数；原车辆模型及其输入合同单独保留。

原车辆联合模型训练包含 1073 条 CFD 样本和 26 辆内置参考车，后者仅有 Cd，Cl 通过损失掩码处理。26 辆的 120 km/h、零偏航、移动地面和旋转车轮属于用户指定的标称假设，并非已核实源工况。完整汽车/飞机联合实验使用 4121 条训练、614 条验证、819 条历史测试记录；最近汽车诊断使用 1819/211/227 条。CFD 样本主要是有限基础车型族的变体，不等于同样数量的独立量产车。

## 当前误差来源与证据

1. **工况与数据来源绑定。** Ahmed 来源留出时绝对速度特征约落在训练均值 327 个标准差以外；同一 A 屏蔽绝对速度后 Cd MAE 从 0.036747 降至 0.023295，同时屏蔽长度和速度为 0.022864。该留出同时改变车型、工况和求解器，不能当成纯几何族验证。Re 等无量纲输入减少来源捷径，但无法补出没有配对样本的物理响应。
2. **泛化不足。** 无量纲加扰动对照中，来源等权训练 Cd MAE 从 0.005297 增至 0.007083，历史测试由 0.011860 降至 0.009080。训练拟合更紧不一定改善留出表现；单种子及重复使用测试集限制了结论。
3. **细节提取和监督效率不足。** 全局 A 的 Rim 预测 Cd 标准差约 0.000237，真值约 0.003950。32 个训练样本能够拟合，核回归也能在族内测试样本泛化，说明这些投影含可学习信息；尚不能把损失归因给具体层或某个权重。
4. **混合训练和验证选择存在权衡。** 小幅轮组变化与不同车型、来源之间的大变化共享同一模型及损失。只做来源方差重标度未改善总体 Cd，Cl 变差；源内排序、绝对误差和预测幅度需要共同评价。
5. **增强依赖尺度。** 同一采样扰动对整体任务有益，轮组专训却接近常数输出。该增强同时包含位置偏移、插值和深度噪声，具体影响项尚未分离。
6. **数据覆盖及标签合同不足。** 当前车型族少；26 辆参考车全部参与训练，不能提供独立新车型评估。缺少同车多速度、偏航、地面/车轮条件的可靠配对，以及估计 CFD 数值噪声所需的重复或网格敏感性证据。不同来源的求解器、边界、参考面积和力轴需持续审计；不能量化地声称各项占多少误差。

Cl 接近零时相对误差与符号评价需要小心；Cl/Cd 同时受 Cd 和 Cl 误差影响，应同时记录绝对 MAE、符号错误、有效分母覆盖率与 P95。

## 推荐改进顺序

1. 以匹配的 seed43、44 复验无量纲＋扰动，固定数据、预算、初始化、验证选择和各来源指标；新几何/工况盲测应留在开发之外。
2. 规范车辆输入：上游依据几何长度、速度和可靠流体性质计算或校验 Re/Mach；未知值继续标记未知，并检查输入支持范围。用户仍可输入速度；阻力由实际速度、密度、参考面积及预测 Cd 换算。
3. 在同一已声明工况、参考面积和力轴合同下，对真实改型加入 ΔCd/ΔCl 监督，保留绝对系数损失和共享头。缺失 Cl 继续掩码，先在固定条件的 Rim 样本核验排序、Δ误差、预测幅度和绝对精度。
4. 拆分采样位置、插值和深度噪声，对整体与细节尺度分别测试；不要直接为后视镜等制作局部裁剪图。
5. 保持完整视图，在容量和预算受控下分别测试浅层分辨率、融合通道及池化，再决定是否增加特征维数。
6. 按既有数据边界补充独立车辆、同车多工况及小改型配对：只获取可核验的几何、系数和工况，记录来源、许可、单位、参考面积、力轴和 CFD 数值质量。

240 项软件测试及数据/权重一致性核验已通过；这些检查支持实现和实验可复核，真实气动泛化仍需独立数据验证。
