# 误差原因、整网修正与 Radiant 同案例对照（2026-11-16）

## 结论

**本轮找到了当前模型没有充分利用轮组细节的直接证据，并做出了在相同92个Rim查询、相同3个训练参考车下，Cd误差低于所测Radiant默认SDF包的多尺度候选。** 三参考平均Cd MAE为0.002992，Radiant为0.003987；各参考下均改善，也超过完全不响应几何变化的参考值基线。

另一项完整实验是三种子整网联合续训。它改善了综合Cd/Cl误差，但对轮组细节的利用依然较弱。综合验证集选择三种子直连集成，多尺度候选在轮组专项比较中更好；这两个结果分别报告，不能把它们组合成某个不存在的模型成绩。

当前固定比较基准仍为 `outputs/vehicle-absolute-readout-20261116/candidate/model.pt`，SHA256 `799ce27f8bae0e2518cb3c68cac97ddb8d0b20e08589ab9a6cbb4ce011e00f4e`。原权重均保留，旧默认接口没有替换。没有增加车辆类别/场景输入，也没有拆分Cd/Cl输出头。

## 原因1：轮组几何信息几乎没有影响当前预测

对训练数据做同来源内的完整五视图打乱，条件向量和目标标签保持原样。使用原CNN的已核验池化缓存，10次独立排列，均值如下：

| 训练来源 | 原Cd MAE | 打乱视图后的Cd MAE | 原Cl MAE | 打乱视图后的Cl MAE |
| --- | ---: | ---: | ---: | ---: |
| AhmedML | 0.007601 | 0.039790 | 0.026271 | 0.220570 |
| DrivAerML | 0.004878 | 0.019155 | 0.021284 | 0.074269 |
| DrivAerRim | 0.002887 | 0.002898 | 0.016707 | 0.016722 |
| WindsorML | 0.008090 | 0.035827 | 0.046926 | 0.320010 |

Rim的720条训练记录换错几何后误差几乎不动，说明当前模型在训练侧已接近忽略轮组差异。其Cd预测标准差约0.000070，真实标签约0.003715。其他三组的打乱明显破坏预测，表明网络已利用较大的车身形状变化。

这能定位“轮组细节没有充分学到”，不能直接证明某个具体卷积层是唯一根因，也不能将梯度或attention解释为部件气动力贡献。

## 原因2：细节与整体变化处在不同尺度，混合训练有局部冲突

采用仅由train计算的统一均值/标准差，对5120维压缩前表示测量几何差异。每来源固定抽取512对训练记录，均方根特征距离的中位数为：

| 来源 | 同来源几何变化的典型距离 |
| --- | ---: |
| Rim | 0.0344 |
| DrivAer | 0.6192 |
| Windsor | 0.6922 |
| Ahmed | 0.7206 |

这些是当前表示坐标中的距离，不能解释为物理距离或气动贡献。它们说明一个全局读出尺度需要同时处理幅度相差很大的变化，这解释了此前专用Rim探针的收益难以直接转移到混合模型。

另在当前固定基准上，每个CFD来源抽取6批×16条训练记录，只算梯度、不更新权重。CNN平均梯度的来源间余弦中，Rim/Windsor约−0.346，Ahmed/DrivAer约−0.214，Ahmed/Rim约−0.132，DrivAer/Rim约−0.116。Rim的平均Cd/Cl CNN梯度范数约0.0192/0.0776，Windsor约0.1427/0.6457。

这些数值表明当前参数附近既有弱细节信号，也有来源之间的局部更新冲突。它们不是整个训练轨迹的全局证明；本轮通过实际训练和读出修正检验这条线索，没有根据几次梯度测量直接修改权重数值。

## 原因3：部分来源还存在更大的泛化差距

固定基准在Windsor的train/test Cd MAE为0.008090/0.014433，Cl MAE为0.046926/0.074418。Rim对应的train/test Cd MAE为0.002887/0.003120，Cl为0.016707/0.015418。

因此，Rim的主要现象是训练侧细节欠拟合，Windsor还存在明显训练—测试差距。仅改善最后的预测头，难以同时消除两类问题。本轮没有增加新的独立车族、速度或偏航覆盖，仍不能把已知车族的变体精度推广到任意新车型。

## 已完成的修正1：完整网络联合训练

对照组为原结构；处理组在原共享头之外增加一条 `5120维完整池化特征 + 36项无量纲输入/掩码 → 128 → 64 → Cd/Cl` 的残差路径。128层使用样本内LayerNorm，最后一层零初始化，起始函数与原模型一致。保留完整五视图，所有原CNN、投影、条件编码、attention和输出头一起更新。

种子42/43/44，每组续训12轮，每次684个优化步、21828次训练抽样；同种子的两组逐样本抽样轨迹和曝光计数相同。Adam学习率1e-4，不增加扰动以隔离结构因素。每次都实际训练26辆内置车，缺失Cl继续掩码。数据为1819 train、211 val、227 historical test。

训练损失仅为原系数单位Cd MAE+Cl MAE。每次仅用val选择两项均不劣于固定基准的最小和；未达门槛时回退epoch0。控制42/44回退，控制43选第9轮；细节42/43/44分别选第10/9/11轮。三个细节权重均确认CNN张量发生更新。

| 同种子选中模型，四来源等权test MAE | 对照Cd | 细节直连Cd | 对照Cl | 细节直连Cl |
| --- | ---: | ---: | ---: | ---: |
| 42 | 0.008325 | 0.008311 | 0.040120 | 0.039439 |
| 43 | 0.008470 | 0.008387 | 0.039302 | 0.038200 |
| 44 | 0.008325 | 0.008208 | 0.040120 | 0.038971 |
| 三次均值 | 0.008374 | 0.008302 | 0.039847 | 0.038870 |

三次配对中两项MAE都下降。神经组部署候选预先定义为三个种子等权集成，而非选择test最好的种子。

## 已完成的修正2：同时处理细小和较大变化的读出

增加固定六尺度Gaussian核的等权混合，尺度为0.03、0.1、0.3、1、3、10。每个核都作用于完整的5120维池化特征及既有36项条件/缺失掩码；没有手动部件裁剪，也没有数据来源或车型类别入参。

该分支复用原CNN，不更新神经权重，采用所有训练来源的真实可用Cd/Cl标签拟合加权核岭回归。所有归一化和参考向量都来自1819条train；1793个Cl标签参与拟合，26个缺失Cl对应的核系数为零。固定12个候选只比较6种正则强度和直接/残差两种形式，val选中alpha=0.1的残差形式。

这是针对特征尺度差异的一项确定性修正，与六次整网训练计算预算不同。它没有使用Radiant预测作为教师，也没有用外部测试误差选参数。

## 与 Radiant 的共同任务

使用既有、已与实际单参考接口对账的Radiant默认SDF包数值。对92个相同Rim查询，双方使用同一个训练参考车的真实Cd。我们的绝对头按 `参考CFD Cd + 查询预测Cd − 参考预测Cd` 得到同口径的绝对Cd；Radiant使用其实际参考预测输出。报告绝对Cd误差，不用升阻比、排序或比例误差选模型。

查询标签只进入评分器。三个参考车0001/0003/0004都来自train，没有按误差重新选参考车。模型训练/选参使用的是所有车辆来源，以下成绩是其中固定Rim子集的比较。

| 共同参考车 | Radiant SDF Cd MAE | 原CNN Cd MAE | 新整网集成Cd MAE | 新多尺度Cd MAE |
| --- | ---: | ---: | ---: | ---: |
| Rim0001 | 0.004299 | 0.004089 | 0.004054 | **0.002834** |
| Rim0003 | 0.003747 | 0.003577 | 0.003686 | **0.002973** |
| Rim0004 | 0.003915 | 0.003264 | 0.003245 | **0.003170** |
| 三参考平均 | **0.003987** | **0.003643** | **0.003662** | **0.002992** |

多尺度与Radiant的配对MAE差为−0.000995，95%配对重采样区间[-0.001371,−0.000635]。重采样单位是92个查询，每个查询的三个参考结果一起保留，未把276个相关结果当成独立样本。

这92条记录已经用于历史开发；区间没有覆盖反复设计选择的偏差、外部模型预训练曝光差异或新车族不确定性。

完全不响应几何、始终输出已知参考Cd的控制组，三参考平均MAE为0.003648。多尺度相对它的差为−0.000656，95%区间[-0.000951,−0.000360]；整网集成相对它没有明确改善。因此，**本轮轮组细节的有效进展来自多尺度读出，不能归功于整网直连集成。**

Rim没有参考修正的直接绝对Cd MAE为：原CNN 0.003120、整网集成0.003051、多尺度0.002741；仅输出训练均值的Rim专用控制为0.002961。此控制有助于识别“接近常数也能取得低MAE”的问题，不能直接部署为通用车辆预测器。

多尺度在Rim直接Cl MAE为0.015682，原CNN为0.015418，存在小幅退步；本轮轮组专项优势主要体现在Cd，不能连带宣称Cl也更好。

## 修正是否真的利用了轮组信息

Rim训练侧数值条件完全相同；对逐样本独立的预测排列，等价于打乱完整几何并保持条件不变。本轮另用同一固定排列比较三种输出：

| 方法 | 正确几何train Cd MAE | 打乱几何train Cd MAE |
| --- | ---: | ---: |
| 原CNN | 0.002887 | 0.002900 |
| 整网直连集成 | 0.002847 | 0.002904 |
| 多尺度 | **0.002487** | **0.003126** |

多尺度的预测确实依赖正确几何配对；它还在相同的留出查询上超过零响应控制。两项证据共同支持“更充分利用了当前特征中的细节信息”。全体误差的唯一起因仍未得到证明。

## 边界与交付

所测Radiant为缓存的默认SDF包，完整源网格派生输入已核验；线上部署身份、外部预训练数据曝光仍未知。我们已经训练720条Rim记录。这是固定任务下的模型能力比较，不能据此排名CNN与SDF架构，也不能推广到所有汽车或飞机。

当前Radiant代码的总Cl求和路径已核实为Clf+Clr，但所测权重的升力参考面积/力轴及参考标签约定仍未与公开Rim总Cl对齐，本轮不宣称Cl优于Radiant。公司代码、权重、嵌入均未复制进个人仓库；这里只使用原来导出的公开几何预测数值。

产物：

- `outputs/vehicle-end-to-end-20261116/ensemble.json`：综合验证集选出的三个完整网络权重清单。
- `outputs/vehicle-multiscale-readout-20261116/model.pt`：多尺度完整几何预测器，包含原CNN和训练侧核读出。
- `accuracy-selection.json`、`comparison.json`、`decision.json`：选择记录、逐案例结果和最终决定。
- `diagnosis.json`、`geometry-permutation.json`、`rim-response-check.json`：训练梯度、表示差异及几何信息利用证据。
- `reference-baselines.json`：相同参考值控制和Rim训练均值控制。
- `verification.json`：66份原产物未变；6次训练各684步；训练记录/缺失标签和选轮核验；多尺度系数满足加权岭方程，残差小于4e-13。
- 完整五视图回放覆盖每个来源和DrivAer11，与评分路径的最大系数差小于9e-7。DrivAer11原始STL回放与缓存完整视图逐值一致；单次完整预测含权重读取和渲染，集成约1.78秒、多尺度约1.69秒。这是单案例暖进程实测。
