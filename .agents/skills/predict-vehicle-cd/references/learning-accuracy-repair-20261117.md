# 梯度冲突、参数平均与统一细节校正实验（2026-11-17）

## 结论

**本轮只有综合Cl取得小幅改善，Cd保持上轮综合候选的结果；轮组Cd细节与Windsor泛化差距仍未修好。** 去冲突和参数平均均未带来验证集Cd/Cl双指标收益，因此最终模型继续使用上轮的神经网络底座，仅启用新拟合的Cl残差校正。

比较基准为[上轮三种子整网集成](learning-end-to-end-radiant.md)，不再将更早、更弱的模型当成本轮基准。所有选择先在211条val上完成，再评分相同227条历史test；指标均为四个CFD来源等权的绝对MAE。

| 方法 | test Cd MAE | test Cl MAE |
| --- | ---: | ---: |
| 上轮综合候选 | 0.008235 | 0.038335 |
| 普通续训 | 0.008227 | 0.038427 |
| 续训+参数平均 | 0.008183 | 0.038416 |
| CNN源梯度去冲突 | 0.008172 | 0.038375 |
| 去冲突+参数平均 | 0.008185 | 0.038446 |
| **最终统一候选：原底座+Cl残差校正** | **0.008235** | **0.038034** |

各神经方法均为三个种子的等权集成，没有选test最好的单个种子。最终候选的Cd在2257条缓存评分记录中与上轮综合候选逐值一致。Cl MAE减少0.000302；按来源进行5000次配对重采样，MAE差95%区间为[-0.001065,+0.000511]，仍包含零。候选作为可复查产物保留，旧默认未替换。

## 修正1：保持原损失，只处理共享CNN的源间梯度冲突

参考[Gradient Surgery for Multi-Task Learning / PCGrad](https://arxiv.org/abs/2001.06782)的投影思想，本轮采用有界的两两变体：每批从实际出现的CFD来源中均匀抽两个来源；若其共享CNN梯度内积为负，分别扣除沿另一个原始梯度的反向分量。其他参数、其他来源保持普通梯度。

所有来源的损失分量使用整批的已观测目标数量作为分母，求和严格对应原Cd MAE+Cl MAE。没有改变标签、目标单位、Cd/Cl共享输出或源采样份额。26辆内置车继续正常参与Cd训练，因其工况含假设，未纳入本轮梯度配对对象。来源ID仅用于训练分组，推理不新增车型类别或数据来源输入。

这项实现只处理每批抽到的一对共享CNN梯度；其他来源关系、投影层和输出层的梯度并不因此获得全局协调保证。

三次投影训练分别实际触发234、238、234次，共706次。被处理的梯度对，原平均余弦约−0.2309，处理后的最小余弦为+0.000338。实现确实完成了所定义的局部冲突处理，但最终Cd/Cl没有同时改善，不能把“梯度计算正确”当成准确度提升。

## 修正2：参数滑动平均

每次训练同时维护衰减系数0.99的参数滑动平均（EMA）。原始权重和平均权重来自同一训练轨迹，没有额外抽样或增强；分别只通过val选轮次。GroupNorm没有运行均值/方差，既有输入归一化缓冲保持固定。

两组训练从各自种子的上轮选中权重开始，种子42/43/44，每次8轮、456个优化步、14552次抽样曝光，Adam学习率5e-5。六次训练全部完成，同种子两组的抽样和曝光计数完全一致。投影组需要额外梯度计算，实际耗时高于对照，不能称为同计算量比较。

单种子选中的轮次如下，0代表完成全部8轮后按验证规则回退起点：

| 种子 | 普通续训原权重 | 普通续训EMA | 去冲突原权重 | 去冲突EMA |
| --- | ---: | ---: | ---: | ---: |
| 42 | 4 | 0 | 0 | 0 |
| 43 | 0 | 1 | 0 | 1 |
| 44 | 4 | 4 | 2 | 3 |

集成模型的val结果：

| --- | ---: | ---: |
| 上轮综合候选 | 0.009573 | 0.041019 |

这些新集成的Cl验证误差均高于上轮候选。选择规则同时要求整体Cd/Cl、Rim Cd、Windsor Cl不劣于上轮，最终底座因此选择上轮集成。这一决定在读取本轮test和Radiant误差前已封存。

## 修正3：将多尺度残差接到综合模型后面

已交付一个统一预测入口：同一完整五视图和无量纲工况经过选中的神经集成，再由多尺度核预测其剩余系数误差。它复用冻结的5120维完整视图特征和36项数值/缺失掩码，核尺度仍为0.03、0.1、0.3、1、3、10。用户无需提供参考车或选择车型类别。

两项输出共享几何表示与核，分别选择岭正则强度。每项只有6个预先固定强度及零校正回退。训练使用1819个Cd、1793个实际Cl标签，26个缺失Cl继续掩码；均值、尺度、参考向量、拟合系数全部来自train。没有使用Radiant预测作为教师。

Cd候选的val整体MAE均劣于原底座，零校正被选中。Cl选择正则强度1.0，val整体MAE从0.041019降至0.040689，Windsor val Cl从0.070512降至0.069137。两项选择和最终组件哈希都在test评分前保存。

这一结果说明“把上轮多尺度模型直接合入综合模型，就能保留各自最好成绩”尚未成立。本轮统一模型只保留了通过门槛的Cl校正，上轮轮组Cd更强的多尺度模型仍作为独立实验产物保留。

## 逐来源结果与未修好的部分

最终候选的Cd与上轮综合候选相同，Cl变化如下：

| 来源 | 上轮test Cl MAE | 统一候选test Cl MAE |
| --- | ---: | ---: |
| AhmedML | 0.041178 | 0.040717 |
| DrivAerML | 0.022867 | 0.022171 |
| Rim | 0.015506 | 0.015210 |
| WindsorML | **0.073790** | **0.074036** |

前三个来源有小幅改善，Windsor退步。Windsor的训练Cl MAE从0.033456降至0.019595，测试却从0.073790升至0.074036，训练—测试差距进一步增大。普通续训、EMA、去冲突也没有改善该来源的测试Cl。因此，本轮不能宣称已经修好Windsor的泛化问题。

![Windsor generalization gap](../../../../outputs/vehicle-accuracy-repair-20261117/windsor-gap.png)

本轮排除了“直接应用这套局部梯度投影或EMA就能解决问题”的简单判断。它没有证明梯度冲突完全无关，也没有分离几何覆盖不足、标签噪声、输入表示不足各自的贡献。下一项有依据的工作是核验Windsor高误差留出样本的几何分布与标签一致性，而非宣称已找到唯一根因。

## 交付和核验

输出根目录：`outputs/vehicle-accuracy-repair-20261117/`。

- `protocol.json`、`draws-{42,43,44}.npy`：冻结的预算、样本顺序、损失、选择规则和输入/代码哈希。
- `control-*`、`projected-*`：六次完整训练记录；每次分别保留`raw.pt`和`ema.pt`。
- `neural-selection.json`、`correction-selection.json`：神经底座及两项残差的验证集选择。
- `model.json`、`correction.npz`：统一模型入口及实际拟合的校正，组件路径与哈希可核验。
- `comparison.json`：每个方法的按例预测、每来源train/val/test绝对误差、配对种子和Radiant同口径结果。
- `verification.json`：84份原产物哈希未变、281项相关测试通过；预算/选轮/内置车实际参与核验；共享梯度投影与原始损失掩码核验；Cl岭方程残差小于7e-14。
- 完整视图回放覆盖全部来源加DrivAer11；原始DrivAer11 STL预测与缓存视图一致。单次包含组件哈希核验、权重读取与渲染约2.24秒，为单案例暖进程实测。
