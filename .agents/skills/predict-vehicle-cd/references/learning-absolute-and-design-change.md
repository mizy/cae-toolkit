# 整车系数、零件替换和连续变形的精度核验

2026-11-18。评估起点为用户保留的在线扰动第5轮。设计任务需要给出同一工况下的基准系数、改型系数和带符号的差值。本次分别以真实轮组替换、可连续调节的后视镜和整机飞机为例，检查预测能否用于设计判断。

**在当前Rim车身内，模型对较大的轮组变化有排序能力。对真实变化不超过0.001 Cd的696个历史测试配对，标称采样下方向正确率为56.6%，ΔCd MAE为0.002103。后视镜的结构变形会改变网络输出，但仅改变渲染采样就能翻转预测方向。** [换件与变形实测](../../../../outputs/aero-absolute-view-audit-20261118/designs/results.json)

1. **绝对输出对小改型过于平坦。** 对92个未参与训练的Rim轮组做4186个无序组合。用第5轮单车绝对输出相减，Cd方向为48.5%，幅度斜率接近0，Cl方向为53.1%，斜率0.004。用同一检查点的512配对读出，Cd方向为72.8%，斜率0.471，Cl方向为58.0%，斜率0.081。斜率以真实Δ为横轴，理想值为1。压低单车平均误差本身对同车身小范围内的排序和幅度约束很弱。
2. **名义偏差和采样漂移都存在。** Rim绝对Cl的历史测试平均有符号误差为−0.02931，MAE为0.03158。即便完全复现原采样，这个偏差也存在。COCOANet的Cl MAE为0.10586，占819条记录全部绝对Cl误差之和的45.2%。HiLift在4°、12°、22°的Cl MAE分别为0.04150、0.02675、0.10193，误差还随工况变化。这些比例按本批记录计数，不等同于因果贡献。
3. **网络使用几何的程度随来源而异。** 在HiLift验证集，同一攻角的18个不同几何按源Mach、参考弦Re和力轴比较，跨10个攻角共有1530个相关改型对。第5轮绝对输出的Cd、Cl方向率为89.0%、89.6%，幅度斜率为0.895、0.723。Rim上的近常数响应不能套用于所有载具。
4. **分辨率与训练任务共同影响细节。** 在同92个Rim验证几何上，把512配对读出改喂真正的256缓存，Cd方向从64.2%变为46.9%。反过来把256绝对读出改喂512，单车Cd MAE从0.00457增到0.02322。交叉输入属于诊断。第5轮绝对路径按全池Cd标准差0.1291标准化，配对路径按Rim差值标准差0.005264标准化。同样的0.001系数残差在两个目标中的量级不同，不能据此直接换算实际梯度比例。[分辨率对照](../../../../outputs/aero-absolute-view-audit-20261118/designs/results.json)

### 用已知基准提高同车身的绝对系数精度

三个预先固定的训练参考轮组各有整车CFD系数。对查询几何 $g$，计算 $F(g)=\frac{1}{3}\sum_a[C_{\rm CFD}(a)+\widehat{\Delta C}(a,g)]+b$。其中 $b$ 为其余717条训练记录的逐系数中位残差，得到Cd −0.000216、Cl +0.006842。训练侧确定公式和偏置，验证和历史测试仅作评分。该估计适用于相同车身、工况与系数定义。[训练标定记录](../../../../outputs/aero-absolute-view-audit-20261118/references/train-calibration.json)

| --- | --- | --- |
| 第5轮原单车输出 | 0.004569 / 0.026434 | 0.003562 / 0.031575 |
| 训练系数中位数 | 0.003125 / 0.015487 | 0.003038 / 0.015473 |
| 三个参考CFD＋预测差值 | 0.002722 / 0.014429 | 0.002254 / 0.016227 |

标定后相对原单车路径在同族历史测试上的绝对Cd/Cl MAE降低约36%/52%。大部分改善来自已知参考与配对读出，增加常数偏置这一步单独看，历史测试Cd略变差、Cl改善。使用同一组参考，偏置在两次预测相减时严格抵消。该估计的历史测试差值方向为Cd 73.2%、Cl 57.8%，幅度斜率0.463、0.077。它提供一个系数和差值相互一致的同族对照，微小设计变化仍需单独验证。[逐查询估计与误差](../../../../outputs/aero-absolute-view-audit-20261118/references/results.json)

## 每个视图的采样稳健性

对单几何绝对预测 $F$，设允许视图组合的最小、最大预测为 $L_g,U_g$。若改型和基准可各自换采样，两次预测之差的有限范围为 $[L_B-U_A,\ U_B-L_A]$。两个端点能独立选择时，这个极值按系数逐项可达。该区间跨零表示仅采样选择就可能翻转排序。该区间完全位于零的一侧仅证明所测扰动下的预测符号稳定，判断真实方向还要同工况CFD或独立校准残差。

对非线性的直接配对头另做了真实512测试。12个验证轮组形成66对，逐视图遍历双端点偏移，并测试全视图共同偏移及预先固定的128组混合偏移，共273种设置。65个真实Cd非零对全部出现可翻转的预测方向，66个Cl非零对也均出现翻转。任一反例都足以否定该对的普遍采样不变性。样本限于同一车身族，所测配置属于压力测试。

## 下一版如何面向实际设计目标

1. **验收同一条设计链。** 同一次评估输出基准和改型的绝对Cd/Cl、带符号的ΔCd/ΔCl，以及视图采样导致的预测区间。用原有强绝对模型与第5轮配对模型各自作为对照。单车绝对误差、改型方向、幅度和差值误差都需要过关。已有参考CFD时，同时比较直接相加的基准系数＋预测差值，注明参考的适用车身和工况。
2. **让绝对预测直接学习改型。** 绝对头使用全部已核验的车辆和飞机真实系数。对同工况的基准和改型，用真实系数差监督 $F(B)-F(A)$。保留配对分支时，让两条路径在真实有标签的改型对上对账，分别核验两者相对CFD的误差。按改变量级和改型类型分层抽样，保留明显变化的幅度，同时提高小变化在损失和验证中的权重。按原系数单位给Cd、Cl分别排名。只动配对读出的旧计划只能优化设计差值，如需改善单车绝对误差，必须包含绝对输出路径或其标定。
3. **同几何做采样约束，真实改型给CFD差值。** 训练中混合完整视图的原采样、单视图扰动、多视图独立扰动，改型两端既共享也独立换采样。用原始几何重渲染已登记、同尺度的相机和网格，保证几何外形、地面位置和数值工况一致。部署使用共用的规范采样。先核查最小待识别部件在输入中可见且可分辨。若两个几何在全部输入中完全相同，确定性预测只能输出同一数值。可见但对下采样十分敏感时，再对照抗混叠前处理、受影响视图的分辨率或原始三维几何补充表示。一般图像网络已有下采样抗混叠的实验，这里的取舍仍需由系数误差检验。[ICML 2019](https://proceedings.mlr.press/v97/zhang19a.html)
4. **给连续变形补真正的中间点。** 第一条可核验的线是上述后视镜的0%、7.5%、15%、22.5%、30%。同一基准车、求解设置、来流、地面车轮、力轴和参考面积下计算整车CFD，用0%、15%、30%作已知点，独立检验7.5%和22.5%的Cd、Cl、变化方向及幅度，同时与端点线性插值比较。对换件另做整套零件留出，对迁移另做整台基础车留出。先用重复计算或收敛历史确定CFD本身能分辨的差值，再决定小Δ方向统计阈值。上述五档的改型CFD尚待取得。
5. **用目标误差决策。** 若任务是分清0.001的ΔCd，直接给出目标区间内的ΔCd MAE、方向率、采样漂移P95、跨零率和可判定覆盖率。可为每对设计给出带误差校准的区间。区间跨零标记为“增减方向待核验”，区间在零的一侧且有同类独立CFD校准时，才用于工程排序。先按车辆与固定翼分别比较标称绝对MAE，再约束各来源和各视图的退化。姿态、迎角、偏航、车轮运动或参考面积的真实变化应沿工况路径预测。

固定速度、密度和参考面积 $A$ 时，$\Delta D=\tfrac12\rho U^2 A\,\Delta C_d$，纯气动功率变化为 $U\Delta D$。若参考面积也变，使用 $\tfrac12\rho U^2(C_{d,B}A_B-C_{d,A}A_A)$。以Rim的140 km/h、1.204 kg/m³、2.16 m²为例，0.001 Cd约合1.97 N和76.5 W。预先固定的0001→0002实际CFD ΔCd为+0.001600（+3.15 N），第5轮直接预测+0.002891（+5.68 N）。整车总能耗还取决于行驶工况和其他功耗。[NASA阻力方程](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/drag-equation/)

## 复核与入口

本轮使用固定第5轮权重，仅参考轮组实验在训练侧拟合两个常数。26辆内置车的缺失Cl仍由原合同屏蔽。24个真实几何的原采样回放误差为0，绝对头缓存组合与完整前向的最大实测误差为2.14e−7，直接配对完整回放与缓存组合差异不超过1.59e−7。训练偏置对所测两两差值的最大影响为2.78e−17。390项测试通过，原有157份保护产物的哈希一致。已反复使用的验证及历史测试数据限定了精度结论的适用范围。[核验清单](../../../../outputs/aero-absolute-view-audit-20261118/verification.json)

- `absolute_view_renders.prepare`复用`phase_views.camera_views`、`canonical_points`及`merge_depth`生成完整几何相位并核验原图。
- `absolute_view_audit.run`复用`joint_sampling.load_checkpoint`、原五视图投影、注意力及绝对头，直接评分单视图与独立组合。
- `design_change_audit.run`复用`PairedDelta.predict_pair`、几何相位缓存及已有`edit_mirrors`，对轮组替换和连续变形作实际回放。
- `rim_reference_coefficients.run`复用同一配对入口，输出统一参考下的逐车绝对估计和717条训练记录的标定值。
