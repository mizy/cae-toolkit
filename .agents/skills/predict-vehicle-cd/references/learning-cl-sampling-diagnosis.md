# 第5轮Cl采样误差：定位与下一步方案（2026-11-17）

## 结论

继续保留`aerodynamic-online-jitter-20261117/retained-online.pt`作为起点。本轮完成了组件交叉、逐视图/逐相位诊断、训练侧梯度检查，以及两组只拟合Cl输出行的快速修复探针。**当前定位优先指向：下视图采样变化被配对读出放大，以及相位之间存在取舍。没有发现Cl缺失掩码错误或第5轮权重损坏。** 未找到同时通过全部保护规则的新权重，第5轮没有被替换。

下一步优先固定第5轮CNN和全池辅助系数头，补足真实重渲染的相位覆盖，针对adapter和隐藏读出小步训练，并逐相位保护真实ΔCd/ΔCl方向和幅度。该方案没有新增推理输入、类别或局部图，也不改变推理网络结构。

## 1. 误差具有明确的相位方向性

以下均为同一批12个验证几何、真实512重渲染，相同物理几何的真实Δ为0。没有使用测试分数选择组件。

| 相位：像素 | 原B假ΔCl MAE | 第5轮假ΔCl MAE |
| --- | ---: | ---: |
| 水平+0.25 | 0.006185 | 0.010527 |
| 水平−0.25 | 0.019027 | 0.008025 |
| 竖直+0.25 | 0.005437 | 0.004193 |
| 竖直−0.25 | 0.008864 | 0.002012 |
| 四相位平均 | 0.009878 | 0.006189 |

第5轮四相位平均改善37.3%，水平正向却退化。因此，先前验证平均改善与主测试水平+0.25退化可以同时成立。后续选模必须看最差相位及各相位指标，不能只看合并平均。

第5轮水平正向的Cl假变化均值为+0.010527、跨几何标准差仅0.001639；水平负向均值为−0.008025。这表现为随采样位置变化的共同偏移，不是几何或真实气动力变化。

## 2. 主正向误差尤其依赖下视图

保持其他四个完整视图不变，仅替换下视图为真实水平+0.25相位：

| 网络 | 假ΔCl MAE |
| --- | ---: |
| 原B | 0.007668 |
| 无扰动续训第5轮 | 0.018773 |
| 在线扰动第5轮 | 0.011401 |

第5轮下视图单独扰动产生的偏移几乎一致，标准差约0.000177；这说明同一车身的栅格变化对读出产生很强影响。五视图共同变化时结果为0.010527，存在非线性相互抵消。四相位合并时右视图也敏感：第5轮右/下单视图假ΔCl MAE为0.007119/0.007842。

这些是网络输入干预结果，不能解释成下视图或某零件的空气动力贡献。

## 3. 放大作用分布在adapter、隐藏层及Cl输出行

固定同一个第5轮CNN、同样的验证特征，仅改变差值读出的参数来源：水平正向Cl假差值用原B完整读出为0.001898，用第5轮读出为0.010527。第5轮下视图特征的四相位变化RMS反而比原B低约8.8%，所以不能把输出误差增大简单归为CNN整体失效。

进一步只恢复一个读出阶段：

| 在第5轮上恢复为原B的部分 | 水平+0.25假ΔCl MAE |
| --- | ---: |
| 不恢复 | 0.010527 |
| adapter | 0.006670 |
| 隐藏读出 | 0.007240 |
| Cl输出行 | 0.008706 |
| 参数编码器 | 0.010529 |
| adapter＋隐藏读出 | 0.003447 |
| adapter＋隐藏读出＋Cl行 | 0.001897 |

16个恢复组合中，adapter、隐藏读出和Cl行的影响在其余阶段的八种条件下均同向；参数编码器在该诊断方向的影响不超过约1.5e-6。当前所有Rim工况本来就相同，未改变Re，本轮结果不能用于判断跨Re泛化。

恢复模块仍有代价：只恢复Cl行保持Cd完全不变，但四相位Cl平均从0.006189恶化到0.006616；恢复adapter降低Cl平均，却使Cd采样误差从0.004786增大到0.008175。**简单拼接旧权重不能同时满足所有要求。** 跨检查点特征与读出存在共同适应，交叉结果只作为定位证据。

## 4. 已排除的错误与仍待分离的机制

- 26条缺失Cl通过finite mask正确排除，原值没有被补零或伪标签替代；内置车Cl对应的实际梯度为0。
- 绝对系数与Rim差值都在各自训练尺度内标准化。没有Cl专属的来源权重，也没有把来源/类别作为新模型输入。
- 原B保持项只约束nominal配对预测。训练增强采用原图双线性平移，而验证采用三角形重新栅格化；soft mask与重新计算的深度/可见轮廓不同，原监督未覆盖这类真实采样变化。
- 控制组也出现Cl采样退化。仅凭控制组对在线组，无法分离全池绝对监督、Rim继续训练、256/512分辨率及优化历史各自的因果份额。

训练侧固定小样本的局部梯度也存在冲突：Ahmed绝对Cd、Windsor绝对Cl与降低Rim真实相位Cl误差的梯度cosine约−0.389、−0.420；COCOANet总体约+0.357，HiLift随batch变号。由此不能笼统归因为飞机数据。这些是42条训练记录、8个训练几何相位上的局部一阶信号，不代表Adam实际轨迹或完整数据总体效果。

## 5. 两种快速修复探针及保幅度结果

冻结整个CNN、adapter、隐藏层及辅助头，只用训练数据拟合原Cl输出行的64个权重。Cd及全池辅助输出由结构保证不变。拟合仅用720个Rim train的冻结配对，以及32个train几何的四个真实相位；验证和开发复测分开封存，未按测试重排。

第一组15个弱ridge候选：验证选出的候选把主测试Cl self MAE从0.010500降到0.002045，但水平+0.125/+0.5的Cl self分别从0.006540/0.005722恶化到0.014685/0.009772；Cl行范数增至原来的77.8倍。这是新拟合探针的病态解，第5轮本身没有这种异常。

第二组45个硬信赖域候选：限制Cl行位移为原范数的5%/10%/25%。全部候选的权重范数不超过原来的1.163倍，40个通过原nominal及合并真实相位响应保护，但没有候选同时满足逐相位Cl采样指标不恶化超过5%的要求。因此保留第5轮，最稳候选仅作诊断归档。

训练特征解释了线性修复的困难：采样特征前两个方向包含90.3%的采样特征能量，同时覆盖70.3%的名义几何差异特征能量。两类特征明显混杂；简单删除噪声方向可能同时改变真实几何响应。这里的特征能量不是Cl物理贡献，也不能证明不存在更好的非线性解。

已有测试集曾多次查看，本轮修复测试属于开发复测，不是新的盲测证据。全部新候选均未替换用户保留的第5轮。

## 6. 下一轮优先方案：真实相位＋受约束读出微调

2026-11-18已实际执行该对照。完整成绩及采样时配准的结果见[采样稳定性验收](learning-stability-first.md)。以下为当时冻结的设计记录。

具体待执行计划保存为最终诊断目录下的`next-experiment-plan.json`，本轮尚未开始此项训练。

这套方案对应了真实采样覆盖不足、读出增敏及视图间抵消三个已观察到的问题，尚无证据证明它能解决全部问题。固定CNN是首轮隔离变量的选择；现有特征中采样与几何差异明显混杂，不能保证仅训练读出就能将二者分开。训练必须同时包含同几何不同采样、真实改型同采样及真实改型不同采样三类配对；若读出实验仍不能守住真实响应，需要进一步验证下视图特征或下采样路径。

下面的方向/幅度门槛允许有限退化，属于候选接受条件，不能保证每条Cd预测完全相同。即便冻结Cd输出行，adapter和隐藏层变化仍会改变Cd；若要求Cd函数严格不变，需冻结其整条计算路径并另做仅作用于Cl的校正实验，该结构尚未实施。

1. 固定第5轮CNN和全池辅助绝对系数头，保留全部4121条记录学到的表示及辅助输出。先只解冻配对adapter与隐藏读出，输出两行及参数编码器保持固定。隐藏层变化仍会影响Cd，因此Cd必须进入监督和验收。
2. 从720个train几何中固定选择64个，补充水平/竖直±0.125、±0.25、±0.5及四个斜向相位。原32个训练相位可复用；几何、工况、标签不变，不增加独立CFD样本数。继续使用五个完整视图。
3. 加入三类零差值对：仅下视图换采样、仅右视图换采样、全部视图换采样。它们都表示同一物理几何；分别监督可防止模型依靠视图间抵消获得低平均误差。
4. 同时保留全部720个训练几何的真实ΔCd/ΔCl监督和第5轮nominal预测保持项。两组单种子42、同配对/更新预算，比较仅续训与增加真实相位约束。CNN只编码一次，读出微调复用缓存；参数不增加，推理路径不增加。
5. 验收固定相对第5轮：每参考/合并/几何两两配对的ΔMAE恶化不超过5%、方向下降不超过3个百分点、正幅度至少保留95%。逐相位单列Cd/Cl self、共同及单侧漂移，按最差相位选模。额外验证±0.375像素，避免只适应训练时的离散位置。全部满足才保留新候选为下一起点。

若以上仍无法通过，再独立测试下采样抗混叠。一般视觉网络的相关方法见[ICML2019原论文](https://proceedings.mlr.press/v97/zhang19a.html)；本项目的气动精度和细节保持仍需单独验证。此前全图滤波与覆盖率约束合并实验已经减弱真实幅度，不能直接照搬。
